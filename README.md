# One True Order

A solo logic puzzle game built with AI assistance using ChatGPT and OpenAI Codex.

## Play

Arrange people from left to right using the clues. Every puzzle has exactly one solution. Choose from three difficulty levels, mark clues as completed, request hints, and check your answer.

## Run locally

Open `index.html` in your browser. No installation or build step is required.

Alternatively, run `python -m http.server 8000` in this folder and open http://localhost:8000.

## Files

- `index.html`: page structure
- `style.css`: styling and responsive layouts
- `game.js`: puzzle generation and game interactions

The stylesheet uses Google Fonts when internet access is available and falls back to sans-serif fonts offline.

## Upload to GitHub

Extract this ZIP, then upload the files inside it to your repository. Put index.html, style.css, game.js, and README.md at the repository root. Do not upload the ZIP itself as a substitute for the source files.

For GitHub Pages, select Settings > Pages > Deploy from a branch, then choose your main branch and /(root).
